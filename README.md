# 📖 Descripción

Proyecto desarrollado en JavaScript utilizando Programación Orientada a Objetos (POO).

El sistema representa un videojuego RPG que permite:

- Crear personajes.
- Combatir enemigos.
- Administrar inventarios.
- Guardar partidas.
- Comprar objetos en una tienda.
- Completar misiones.

# 🧩 Clases del sistema

## Personaje

Representa al jugador del videojuego.

## Enemigo

Representa los enemigos con los que combate el jugador.

## Inventario

Administra los objetos obtenidos.

## Partida

Permite guardar y cargar el progreso.

## Tienda

Gestiona las compras de objetos.

## Mision

Permite completar misiones y obtener recompensas.

QUIERO crear un personaje con nombre y clase

PARA comenzar mi aventura en el juego.

## US03 – Inventario

## US04 – Sistema de niveles
